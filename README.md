# Simon Libon — Site officiel (GitHub Pages)

Site statique (HTML/CSS/JS) prêt pour GitHub Pages.
Le lien TikTok est : https://www.tiktok.com/@simonlibon.music

## Publication
1. Crée un compte sur https://github.com/ (si nécessaire).
2. Crée un dépôt PUBLIC nommé exactement `TON_PSEUDO.github.io`
   en remplaçant TON_PSEUDO par ton véritable pseudo GitHub.
3. Décompresse l'archive ZIP.
4. Dans ton dépôt, ouvre `Add file` > `Upload files` et transfère
   les fichiers décompressés (index.html, site.js, style.css, etc.)
   **directement à la racine** du dépôt, sans dossier parent.
5. Clique sur `Commit changes`.
6. Dans `Settings` > `Pages`, choisis `Deploy from a branch`,
   puis la branche `main`, dossier `/(root)`, et `Save`.
7. Le site sera accessible à `https://TON_PSEUDO.github.io/`
   lorsque GitHub signalera que la publication est terminée.

## Modifications futures
Change les fichiers, puis valide (`Commit changes`) les modifications.
GitHub Pages republie automatiquement.
